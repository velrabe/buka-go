# BukaGo

Упрощённая основа сайта [bukago.app](https://bukago.app/) для дальнейшего обновления дизайна.
Публичные тексты и материалы сохранены по состоянию на 1 октября 2026 года.

## Запуск

Требуется Node.js 20.9 или новее.

```sh
npm ci
npm run dev
```

Статическая версия, без сервера Next.js:

```sh
npm run build
npm run preview
```

Dev-сервер: http://localhost:3000. Статический предпросмотр: http://localhost:4173. Результат сборки — `out/`.
Проверка типов, маршрутов, локальных ссылок и ассетов: `npm run check` после сборки.

## Локальная примерка шрифта

На `localhost` / `127.0.0.1` / `::1` сверху показана небольшая панель «Шрифт» с одним
тестовым Rubik и альтернативным M PLUS Rounded 1c. Выбранный шрифт применяется к заголовкам
и тексту локального предпросмотра.
Сайт использует реальную ширину окна браузера и обычную адаптивную вёрстку.

Оба шрифта подключены локально с кириллицей и латиницей; лицензии OFL находятся рядом
с файлами в `public/fonts/`. Для M PLUS Rounded 1c подключены начертания 400, 500, 700, 800 и 900.
На публичных доменах панель не отображается и сохраняются исходные Nunito + Inter.

`ASSETS-INBOX` зарезервирован в `.gitignore` для локальной папки или ссылки на папку входящих материалов.
Содержимое не публикуется. Используемые на сайте ассеты копируются отдельно в `public/assets/`.

## Устройство проекта

- `src/components/Landing.tsx` — исходный порядок семи разделов лендинга; каждый блок доступен отдельно для редизайна.
- `src/content/locales/` — исходные тексты RU, EN, KK, UZ, AZ.
- `src/content/pages.json` — 174 статьи и 42 локализованные страницы документов, с очищенным HTML.
- `src/content/media.json` — изображения блоков лендинга.
- `src/content/assets.json` — соответствие оригинальных URL локальным файлам.
- `src/styles/_tokens.scss` — цвета, шрифты, отступы, размеры контейнеров и скругления.
- `src/components/FontPreview.tsx` — компактная локальная панель с тестовым шрифтом.
- `public/assets/` — 299 скачанных ассетов, включая исходные иллюстрации и шрифты.
- `src/content/migration.json` — состав переноса и три недоступные статьи из карты оригинального сайта.

Стек соответствует публичной сборке оригинала: **Next.js App Router, React, SCSS**.
Исходник использует Next.js 16.3.3; здесь установлен патч 16.3.8. Nunito и Inter загружаются локально.
Это читаемая реализация из публичного HTML, переводов и ассетов. Серверный исходный код оригинала недоступен через сайт.

## Что сохранено

Структура и тексты лендинга, переключение языков, мобильное меню, якоря и плавная прокрутка,
ссылки App Store / Google Play, Telegram, блог с пагинацией и исходным виджетом «Поделиться», документы, примеры заданий,
cookie-уведомление, цели Яндекс.Метрики и исходный номер счётчика.
Страницы блога и документов доступны по исходным адресам; добавлены совместимые короткие `/blog` и `/legal` адреса.
Числа просмотров статей — снимок оригинала, обращения к его серверу для увеличения просмотров не выполняются.
Сохранены страница `/survey/`, её тексты и переход в исходную Google Форму. Коммерческие формулировки на ней перенесены из оригинала без проверки актуальности.

Облака, параллакс, автоматические декоративные циклы, сложные наложения и старые JS-бандлы не исполняются.
Минимальные стили дают адаптивную сетку, типографику, простые кнопки и границы.
Декоративные изображения сохранены среди ассетов для дальнейшей работы, но не используются как слои оформления.

## Внешние сервисы

**Аналитика.** Исходный счётчик `110909899` запускается после принятия cookie и только на доменах
из `NEXT_PUBLIC_ANALYTICS_HOSTS`. На localhost запросов в рабочую Метрику нет.
Цели скачивания, Telegram и подписки сохранены. AppMetrica smartlink сохранён в `src/lib/settings.ts`;
кнопки магазинов используют прямые адреса, как публичная разметка оригинала.

**Рассылка.** Оригинальная отправка использует `/api/auth/wait-list`, серверные cookies/CSRF и CAPTCHA.
Эти части невозможно перенести одной статической выгрузкой. По умолчанию модальное окно отправляет
пользователя на основной сайт для подписки и не показывает фиктивный успех.
Для нового обработчика задайте `NEXT_PUBLIC_NEWSLETTER_ENDPOINT`: он должен принимать JSON
`{ email, consent: true }`, возвращать `{ success: true, message?: string }`, проверять согласие,
защищаться от спама и разрешать новый origin. Для исходного обработчика потребуется отдельная
интеграция CAPTCHA и серверной защиты; не направляйте на него этот упрощённый адаптер напрямую.

**Поделиться.** Сохранён оригинальный виджет Яндекса для VK, OK, Telegram, Viber, WhatsApp, Моего Мира и LiveJournal.
Его скрипт, магазины приложений, Google Форма и другие внешние сервисы требуют подключения к сети; сами страницы, изображения и шрифты работают локально.

**Индексация.** Статическая основа помечена `noindex`, чтобы её предпросмотры не дублировали основной сайт.
Перед публикацией на выбранном домене настройте canonical, sitemap и robots в метаданных.

## Повторный импорт

`scripts/import-content.py /path/to/original` принимает локальный архив с `manifest.json` и `errors.json`.
Требуется Python и BeautifulSoup4. Импорт очищает HTML, копирует публичные ассеты и извлекает исходные переводы.
Он перезаписывает контент: запускайте его только при намеренном обновлении снимка, сохранив правки.
